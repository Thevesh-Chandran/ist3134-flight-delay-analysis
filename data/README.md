# Dataset locations

Download the dataset from:

https://www.kaggle.com/datasets/hrishitpatil/flight-data-2024

Keep local files in the following ignored directories:

```text
data/raw/flight_data_2024.csv
data/sample/flight_data_2024_sample.csv
data/flight_data_2024_data_dictionary.csv
```

The analysis programs also accept any local path or an `s3://` input path, so
copying the downloaded files into this repository is optional.

Do not commit the full dataset or AWS credentials to GitHub.
